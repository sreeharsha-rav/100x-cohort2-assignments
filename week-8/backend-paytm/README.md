# Backend for Paytm Backend Assignment

## Problem Statement

You have to implement a backend for a payment gateway like Paytm. The backend should have the following features:
- Create a new user with a wallet
- Add money to the wallet
- Transfer money from one wallet to another
- Get the balance of a wallet
- Get the transaction history of user
- authenticate the user and authorize the user to perform the above operations

## Tech Stack

- Node.js
- Express.js
- SQLite
- Sequelize ORM
- Zod for input validation

## Setup

1. Clone the repository
2. Run `pnpm install` to install the dependencies
3. Run `pnpm run dev` to start the server
